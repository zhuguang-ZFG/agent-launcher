# 独立人类可用性检查：执行材料（2026-11-19）

目的：缺口收口计划 P4 与 SPEC §88 把「独立人类可用性检查」列为 G4 前置项。本文给出可直接交给一位**未参与开发的审阅者**执行的清单、环境要求与记录格式。执行完成后把结果（含发现的问题清单）记入 `IMPLEMENTATION.md` 新章节，并按 `docs/ACCEPTANCE.md` §8 的 UX 编号映射。

## 1. 审阅者与环境

- 审阅者：未阅读过本仓库源码与设计文档的成年 Windows 用户（最好同时是重度中文输入用户）。
- 机器：Windows 10/11 x64，125% 或 150% 文字缩放至少覆盖一档；不安装开发工具。
- 材料：发货预览包 `artifacts/preview/`（`Start-AgentLauncher.cmd` 入口）、一个含中文路径的真实 Git 项目、已配置好的远程 VPS 槽位（由操作员预先登记，审阅者不知晓凭据）。
- 记录：审阅者边做边写「任务号 / 用时 / 是否完成 / 卡住时的原话 / 界面上任何让它困惑的文字」，可截图。

## 2. 任务脚本（顺序执行，不给提示）

| # | 任务 | 通过判据（审阅者主观完成即可） | 映射 |
| --- | --- | --- | --- |
| T1 | 冷启动双击 `Start-AgentLauncher.cmd`，把项目文件夹拖入窗口，只启用一项，点击「启动」 | 能独立完成；能说清「启动器内」与外置的区别 | U01/U02 |
| T2 | 在打开的终端标签里输入一条中文任务并让 agent 执行 | 能输入、能看到实时输出、明白标签即会话 | U02、嵌入式六门禁之外的真人输入 |
| T3 | 点「返回配置」再加第二项并启动；随后在两个标签间切换 | 两个会话互不干扰；知道哪个标签对应哪个项目 | U02/F02 |
| T4 | 关闭主窗口后从任务栏/开始菜单重新打开，找回仍在运行的会话 | 能找到「Agent 终端」入口并接回画面 | §90 REOPEN |
| T5 | 从运行记录点开一条记录：看状态、看变更、尝试「聚焦终端」 | 能读懂状态文案（含「宿主已退出」这类保留文案）；变更清单能看懂 | UX10/UX12 |
| T6 | 设置：切换主题、文字缩放 150%、外置 Windows Terminal 模式重启一次 | 每项改完界面立即生效；外置模式知道去哪里找终端窗口 | U03/U06 |
| T7 | 远程槽位：把一项指到 VPS 并启动，观察同步徽章与结束后的变更 | 能说出文件最终在哪台机器上；同步徽章文案能看懂 | R29/UX 同步文案 |
| T8 | 主动制造一次资源不足（或由操作员模拟），观察启动按钮与提示 | 能复述提示让他做了什么决定；不觉得被静默拒绝 | R18/R19/ACC-U06 |
| T9 | 主机设置里把同步模式选成「none」并保存 | 被拒收，且能复述为什么（三台同权） | 2026-11-19 新增 |
| T10 | 主机设置里填内存上限 100 并保存，再填 4096 保存 | 出界被拒、合法值被接受；能说出这个上限管什么 | R45 新增 |

## 3. 结果判定

- 每个任务记录：完成 / 部分完成（卡在哪）/ 未完成；原话必须保留。
- 汇总时按 **P0（阻止完成）/ P1（造成错误理解）/ P2（文案或美观）** 分级；P0/P1 归零是 SPEC §189 的 G4 前提之一。
- 审阅者签署一句「本人在上述环境独立完成上述任务」并注明日期与环境；该声明与原始记录一起归档（可放忽略目录，引用路径）。
- 本文不预判结果：即使全部通过，也不宣称 G4（其余前置项各自独立）。

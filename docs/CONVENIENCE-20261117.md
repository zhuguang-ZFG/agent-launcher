# 快捷导航设计与审查

## 方向

- 产品：为同时使用多个 CLI Agent 的开发者提供项目、配置和会话导航。
- 性格：克制、直接、可核对。
- 场景：长时间工作的 Windows 开发桌面，沿用已有中性色、系统字体和强调色。
- 重点：当前项目始终可见，启动按钮仍是主操作。
- 细节：快捷键与真实会话状态说明操作入口，窄窗口保留同样的能力。

按 `unslop` 的轻量修整方式检查；用户已要求直接继续改进操作便利性，本轮沿用既有方向。技能作者 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)），[unslop](https://heydamir.design/unslop)，CC BY 4.0；此处记录使用来源，没有复制技能参考素材。

## 发现与处理

| 原有操作障碍 | 改进 |
| --- | --- |
| 逻辑宽度低于 900 时当前项目、路径、最近项目控件全部隐藏，默认 920 宽在 125% 文字下即出现 | 顶部常驻当前项目按钮和最近菜单，与内容滚动区分开 |
| 运行记录/队列在页面下方，侧栏前三条只有静态文字，需要展开并自行查找 | 摘要可点，按原 ID 展开、滚动和聚焦对应记录 |
| 常用操作分散，已有 Ctrl+O / Ctrl+Enter 不容易发现 | 可见「快捷操作」入口，Ctrl+K 搜索；结果提供 Agent 选择、运行记录、终端召回、等待项、最近项目与既有设置入口 |
| 切换 Agent 调用整页 Render，重建侧栏并重置 ProjectPath 文本 | 只重建当前编辑区，保留侧栏焦点及待确认输入 |
| 最近项目修改在 Render 之后，列表重新赋值未立即刷新；大小写不同会重复 | 成功编辑后同步刷新、忽略大小写去重；失效目录不污染当前项目 |
| 所有未暂缓等待项都显示“等待资源”，即使队列已经暂停 | 分别显示“已暂缓”“范围外”“已暂停”“等待调度” |
| 标题 `AGENT` 与其余中文层级不一致，播放符号不是实际动作 | 使用 `Agent` 标题和带文字的真实导航按钮 |

改动不引入定时器、外部服务、NuGet UI 库或后台索引。搜索窗口按需构建，数据规模由已有配置/队列上限约束。终端召回复用既有按标题查找机制：同标题的不同批次仍可能存在歧义，不宣称精确到窗格。

可执行合同与回归见 C11、UX10；完整验证结果和截图在 `IMPLEMENTATION.md` §79。

# 原生界面重设计 v0.7

用户反馈：v0.6 的 UI 设计不够好。本次针对 WPF 实际界面重做信息层级、控件样式和工作区布局，不修改资源保护与启动合同。

## 审查结论

- 配置行重复出现参数、上移、移除等同等级按钮，完整路径和探测解释使每行过高。
- 单列连续堆叠项目、四个配置、预览与记录，默认尺寸下主流程断裂。
- 容器、按钮、输入框使用相近的强边框，缺少主次；默认控件与自定义颜色没有完整的主题系统。
- 空态即显示错误红字，尚未操作的用户被当作已经出错；资源数字和技术说明占据操作栏。
- 设置要求输入布尔值和英文枚举，属于实现字段，不是可用的设置控件。
- 已生成的 v0.6 截图保留用于对照；当前模型无法直接读取图像像素，审查依据为真实布局实现与控件测量，不声称已看过像素并完成视觉验收。

## 五行方向

- 产品：为 Windows 开发者配置项目与多个 CLI，并一次打开分屏终端。
- 性格：沉着、精确、紧凑。
- 场景：开发工具中的终端启动面板，沿用 Windows 交互习惯和系统字体。
- 重点：真实分屏预览与一个明确的启动动作；背景、边界、次要操作保持安静。
- 识别细节：配置项编号与预览窗格编号始终一致，包括只启用第 1/4 项。

## 布局与信息

顶部为产品名、工作目录和设置。项目面板显示项目名/可编辑完整路径、选择文件夹与最近项目。宽窗口采用左配置、右预览：左侧组合和紧凑配置行，右侧终端示意、目录策略及资源摘要。运行记录默认折叠，启动或需要核对时展开。底部固定显示当前阻止原因、保存状态与启动按钮，取消仅在处理中显示。

配置行固定列：启用、编号、Agent、短命令状态、详情与更多。上移/下移/移除进入更多菜单；程序全路径和参数可在详情中查看，错误摘要不隐藏。未启用项标注未启用，不执行探测。

小于 900 DIP 时右侧移到配置下方；内容区滚动，底部操作不滚动。预览只表达布局，不使用假输出、闪烁光标或伪造运行状态。浅深主题采用统一资源；对话框、下拉菜单、焦点和禁用态一起调整。

## 九层实施

1. 4/8/12/16/24 间距，配置行等高并对齐。
2. 石墨灰中性色、一个蓝色强调；语义警告采用独立文字与背景。
3. 简单终端/文件夹线条；动作保留文字，更多菜单提供可访问名称。
4. 首屏说明缩短，技术细节放入详情，空态不冒充错误。
5. 标题 20、分组 16、正文 14、辅助 12；系统字体，路径使用等宽字体。
6. 宽窗口双栏，窄窗口顺序堆叠，启动固定底部。
7. 统一 6px 控件/10px 面板圆角、hover/focus/disabled、可复制详情。
8. 深色终端分屏示意作为内容视觉重点；没有装饰图片或假数据。
9. 不新增持续动画、模糊或渲染服务，保持 WPF 原生轻量实现。

## 夹具提示词（确定性设计，2026-11-19 实机试跑修订）

**嵌套引号与 `$` 都不可靠**：试跑实证 `bash -c '…$var…'` 的单引号在 pi 工具层丢失；`$((…))` 即使转义也会被某层展开破坏。夹具脚本内容**一律不含 `$`、不含嵌套引号**：先 write 工具写脚本文件（R29 已验证可靠），再 bash 工具前台执行。

- 心跳夹具（R33 与 R45-scope 共用），作为 pi 的单个 prompt 参数（多行文本；360 秒=72 次，试跑用 12 次验证）：
  ```
  First use your write tool to create a file named loop.sh in the current directory with exactly this content (two lines):
  for i in {1..72}; do date +%s >> heartbeat.txt; sleep 5; done
  echo DONE >> heartbeat.txt
  Then use your bash tool to run exactly this command with a tool timeout of 420 seconds: bash loop.sh
  Do nothing else before or after.
  ```
  pi 的 bash 工具前台等待 → pi 进程存活 → 本地 ssh 保持 → 条目 Started。heartbeat.txt 每 5 秒增长是远端活性证明。C# 用逐字字符串 @"…"；ssh 经 ArgumentList 传递，无本地 shell 插值。
- 超限夹具（R45-oom）：同样两步法，alloc.py 内容（无 `$`）：
  ```
  b=bytearray(700*1024*1024)
  print('ALLOC_DONE',flush=True)
  import time; time.sleep(20)
  ```
  prompt 指示 write 工具写 alloc.py 后 bash 工具执行 `python3 alloc.py`（tool timeout 120 秒）。700 MiB > 512 MiB scope → 内核在 scope 内 OOM 杀 python3（最大任务）。判据以 scope 的 `memory.events` 的 `oom_kill` 计数为准，不依赖 dmesg 权限。
- 若 pi 不配合（不执行命令/提前退出）：如实记 FAILED 并保留 worker stdout/stderr 与远端核验输出，不得改用假 ssh 或放宽判据。

- [ ] **Step 1: 实现 RunReattachAsync**

流程：
1. 护栏/配置/planner/reserve/pane 同 RunAsync；prompt=心跳夹具；等 Started + heartbeat 增长。
2. 记录 agent pid（FindAgentPid）与本地 ssh pid（receipt.Pid）。
3. **模拟断线**：独立 ssh（root）沿 agent pid 的 `/proc/<pid>/status` PPid 链向上找到首个 `sshd` 进程（`cat /proc/<ppid>/comm` == sshd），`kill <该sshd>`。不得杀 agent 本身。本地 ssh 应 exit 255 → 条目 Disconnected（轮询确认；若实际不是 255/Disconnected，如实记录实际值并按 FAILED 处理）。
4. 断线后探针：SshAsync 跑 ProbeShell → 必须 ALIVE（trap '' HUP 生效）；heartbeat 继续增长。
5. 负路径：`reattach-remote` 不带确认（`Reattach: new OperatorReattach(false)` 或省略）→ 必须拒绝，账本仍 Disconnected，无 operator-reattach.json。
6. 正路径：`Reattach: new OperatorReattach(true)` → SendAsync（内部自动 poll）→ 条目 Reattaching + operator-reattach.json 存在。
7. 起 `pane <id> reattach` worker，**stdin 保持打开**；写入 `echo REATTACH_PROOF_<nonce> > reattach-proof.txt\r` 再写 `exit\r`（煮熟模式需要 \r，见 §90）；等 worker 退出 → 回执 Disconnected（RunReattach:502）。
8. 核验：独立 ssh `cat <remoteDir>/reattach-proof.txt` 含 nonce；agent pid 与步骤 2 相同（没有重启 agent）；heartbeat 仍在增长；全程条目占名额（status 里非终态计数≥1）。
9. 收尾：杀 token 进程树 → 条目回 Disconnected → release-remote(Gone, confirmed) → Settled；杀 monitor；写证据（transitions、探针输出、proof、pid 对比、ssh 退出码；不含密钥）。
10. 返回 PASS?0:1。PASS 必须全部满足：255→Disconnected、ALIVE、未确认拒、确认挂上、proof 字节、pid 不变、释放后 Settled。

# 缺口收口计划

日期：2026-11-17 起草；2026-11-18 按 `main` `6daa7de` 对齐状态。

对象：`agent-launcher` 技术预览收口，以及把 SSH 远程执行正式纳入规格。  
不重写产品行为。本计划对照 SPEC、CONTRACTS、ACCEPTANCE 和 IMPLEMENTATION，只说明哪些缺口已经有记录、哪些仍然开放。本次对齐不重跑门禁，不新增通过或失败计数。

## 1. 目的

在可以判定 G4 之前，先分清四件事：

1. 规格与代码对 SSH 远程 Linux 主机的范围一致；WSL 仍排除。
2. 已经落在 `main` 并推送的改动，不再被写成未提交或未推送。
3. 远程生命周期里已经落地的操作员确认释放和已记录的真实 VPS 活测，不再被写成待实现；仍然缺失的重连和远程内存上限继续保持开放。
4. 用完整门禁、远端 CI、本机长稳和人类可用性，决定能不能宣称稳定发布。本计划本身不关闭 G4。

  - Mutagen `flush` 失败时保留会话并写入回执，合同要求仍在。本次对齐没有单独复核这条失败路径的证据，不把它标成新关闭项。

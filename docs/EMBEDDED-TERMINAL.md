# 内置终端：当前实现与边界

本文描述 2026-11-27 工作树的实现合同。实际验证结果见 [IMPLEMENTATION.md](IMPLEMENTATION.md)，验收条件见 [ACCEPTANCE.md](ACCEPTANCE.md) §19。它不是完整 VT/xterm 兼容性或所有 CLI、输入法、网络环境的保证。

## 操作

每次尝试对应一个标签。工具栏提供复制、粘贴、搜索、回到最新和重新连接，右侧滚动条显示保留历史的位置。内置模式的配置预览显示标签；设置选择外置 Windows Terminal 后，预览才显示分屏。

| 操作 | 行为 |
| --- | --- |
| 滚轮、滚动条、Shift+PageUp/PageDown | 回看保留的主屏输出 |
| 拖动选择、Ctrl+C | 有选择时复制；没有选择时向 Agent 发送 0x03 中断 |
| Ctrl+Shift+C | 仅复制选择；没有选择时提示选择文本 |
| Ctrl+F、Enter、Shift+Enter | 搜索保留输出、下一处、上一处；同一行多个匹配也可循环 |
| Ctrl+V | 清洗剪贴板后粘贴；多行按协商或确认规则处理 |
| Ctrl+Tab、Ctrl+Shift+Tab | 切换终端标签，不向 Agent 发送 Tab |
| Shift+Tab、Ctrl+方向键 | 发送对应 xterm 修饰键序列 |
| Esc、回到最新 | 清除选择/回看并恢复实时输出；实时无选择时 Esc 送给 Agent |

选择期间保留所选屏幕数组，后续输出不会改变待复制内容。选择范围限当前显示的一屏。搜索为大小写不敏感的连续文本匹配，查询最长 256 个 UTF-16 字符；历史按屏幕行保留，搜索不跨行。旧宽历史行在窄窗中裁切显示，不自动重排，搜索只定位当前可显示列。

## 画面、历史与传输

- `TerminalScreen` 是无 IO 的纯模型；Worker 主线程消费完整字节流并执行尺寸/回读请求，App 不解析原始输出。UTF-8 和控制序列收集缓冲区有界。
- 主屏历史同时受 2000 行和 2 MiB 格子预算约束，任何一项超限就丢最旧行，画面披露累计截断数。备用屏不写入主屏历史。
- 当前屏幕最多 200 列×60 行，生产尺寸请求至少 20 列×4 行。中文宽字符由主体格和续接格组成，横纵缩放保留完整字符，只清除裁切后不完整的半格。
- 实时 `snapshot` 仅含两块当前屏幕、世代、模式、光标、历史行数/截断数及可选退出码。不会逐帧复制或发送全部历史。
- `read` 携带请求 ID、顶行和可选搜索条件；`readback` 返回最多一屏的格子及匹配坐标。App 和 Worker 均合并待处理读取，只保留最新请求；过期、错屏或错尺寸响应不得覆盖当前视图。
- 协议为 4 字节小端长度加 UTF-8 JSON；单帧正文最多 262144 字节。格子数组使用有界行程编码与 base64，输入待发总量最多 64 KiB，超限提示稍后重试，不截断也不建立无界队列。
- 回读必须核对尺寸、历史范围、数组长度、屏幕标识、Unicode 标量、颜色和匹配坐标。失败拒绝应用；不向绘制层传入负匹配宽度或非法字符。

## 粘贴和输入

模型解析 CLI 输出中的 DEC 私有模式 `CSI ? 2004 h/l`，快照携带实际协商状态。只有开启时，粘贴才自动用 `CSI 200~` 和 `CSI 201~` 包裹；包裹由启动器在清洗之后添加。剪贴板中的 ESC/CSI/OSC、C0/C1 控制字符会移除，制表符保留，恶意提前结束括号粘贴的序列不能生效。

未协商时，任何含 CR 或 LF 的粘贴先显示内容预览和“换行可能立即执行命令”的确认，默认取消。取消不发送任何字节；确认后整段发送，CRLF/CR/LF 规范为 CR。已协商的多行规范为 LF。不会逐行拆分为独立命令，也不在管道失败后重放输入。Ctrl+C 是终端输入，不是结束 Job、SSH 或整棵进程树的命令。

## 生命周期

既有 pane Runner 拥有领取、Job、同步和回执；`EmbeddedTerminalHost` 只拥有 ConPTY 和画面。App 通过当前用户命名管道连接，关闭视图或 App 只断开管道。运行中的宿主继续读取并有界保留输出，Agent 的执行与资源保护不依赖视图存活。

失效标签再次聚焦或点击重新连接时，复用原尝试；连接等待最多 5 秒，不新建 Agent。重新打开已关闭的运行视图前，核对宿主 PID 与启动时间，避免 PID 重用。重新连接恢复最新完整屏幕；没有输入重放。

Runner 结束后，账本与资源按原生命周期正常终结。宿主发布含 ExitCode 的终态屏幕，仅为当前连接视图保留有界历史，并继续处理搜索、回看和模型缩放；新输入被忽略。该视图断开后宿主退出。极短任务在从未有视图连接时最多等待 5 秒首次连接，不永久遗留宿主。

界面明确显示“进程已结束，可回看和搜索输出；关闭视图将释放输出”。输出不写磁盘、不提供已关闭终态视图的永久聊天恢复。0 退出码仍不代表代码任务通过验收。外置 Windows Terminal 的关闭窗格行为属于外部终端，不能套用内置的仅分离语义。

## 验证入口

- `tests/AgentLauncher.TerminalModel.Tests`：宽字符、历史预算/搜索、复制、粘贴清洗与确认、修饰键、协议及畸形回读。
- `RunTerminalUsabilityChecks`：WPF 卡片回看、选择、搜索、旧响应与粘贴状态切换。
- `--embedded-check`：隔离 INTEGRATION_TESTS 子进程及真实管道，验证重开、同标签重连、滚出屏幕的历史搜索/复制、中文输入、退出后搜索与缩放、关闭终态视图后宿主退出。

完整门禁仍使用 `scripts/test.ps1`。模型与隔离子进程回归不代替真实 VPS 断网、输入法预编辑、独立人类操作或持续负载验收。
